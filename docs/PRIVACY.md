# 隐私与数据流

MCP 服务在用户指定的机器上运行，插件作者不托管网盘服务，也不收集账号和分析数据。

Codex 将路径、搜索词及下载文件名发送到 stdio MCP 服务；服务将必要参数和 OpenList Token 发往用户配置的 OpenList。OpenList 使用自己的存储驱动访问网盘。工具运行只请求该 OpenList 及其同源代理，不将网盘 Cookie 交给插件作者。

列表、文件名、路径和下载结果会返回 Codex。用户要求读取下载文件时，其内容也可能进入对话上下文。不同产品和用户部署的 OpenList 各自具有相应的数据处理规则。

账号模式通过本机隐藏输入或安全环境提供密码，向用户指定的 OpenList 登录接口发送密码哈希（仍须视作凭据保护），登录 Token 仅保存在进程内存中，不写入磁盘。

Token 和目录密码通过用户权限受限的本机文件或安全环境配置提供；不出现在工具结果、仓库或发行包中。OpenList 自己的数据库、驱动凭据及日志由用户保护。卸载插件不会删除用户的 Token 文件、OpenList 数据和下载资料。

安装时 uv 会访问软件包源；工具运行时没有插件作者的遥测端点。反馈时仅提供移除凭据和私密路径后的问题描述，不发送 Cookie、Token、目录密码或签名 URL。

## 网页关联

关联工具只打开用户指定 OpenList 的专用浏览器配置，只读取该站点的 token 键，不读取账号、密码键或其他站点资料。用户在 OpenList 页面自己输入账号密码。经 /api/me 验证后写入插件独立会话文件：Windows 当前用户 DPAPI，POSIX 0600。专用浏览器配置本身仍保留 OpenList 原生网页登录状态；请勿将浏览器配置或关联文件上传到 GitHub。源码及发行包不含这些数据。
